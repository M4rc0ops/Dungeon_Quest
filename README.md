# DUNGEON QUEST

Dungeon Quest è un GDR che si basa sulla scalata di una torre a tre piani con nemici da affrontare e boss da sconfiggere. L'obbiettivo del gioco è arrivare nella stanza finale in cima alla torre riuscendo a sopravvivere agli attacchi avversari 

# COMANDI DI GIOCO
I Comandi per Giocare a Dungeon Quest sono:

WASD -> Movimento

Z -> Attacco

Esc -> pausa

# COME ESEGUIRE IL PROGETTO

### REQUISITI

I requisiti per compilare ed eseguire il gioco sono:

_Gradle -> versione 9.8.2
 
_Java -> versione 25 (LTS)
 
_Javafx -> versione 25


### ISTRUZIONI

``` bash
git clone https://github.com/M4rc0ops/Dungeon_Quest.git 
cd Dungeon_Quest
```

### BUILD DEL PROGETTO

``` bash
gradlew build
 ```

### ESECUZIONE

``` bash
gradlew run
 ``` 


 # STRUMENTI AI

Sono stati utilizzati due principali strumenti AI:

### • Gemini 

Gemini è stato utilizzato per la generazione totale delle immagini dei tutto il progetto, con modifiche di stile e dimensione secondo gusti personali.

### • ChatGPT

ChatGPT è stato utilizzato come strumento di supporto durante lo sviluppo del progetto, principalmente per:

_ fornire assistenza limitata nella scrittura e nella revisione del codice, ad esempio per individuare e correggere errori di sintassi, battitura e logica;

_ approfondire argomenti trattati durante le lezioni o necessari per lo sviluppo del progetto, quali ereditarietà, principi SOLID, classi enum e altri concetti;

_ individuare e risolvere errori emersi durante la compilazione ed esecuzione del programma;

_ definire i codici alfanumerici e la sintassi delle regole CSS adottate per la personalizzazione dell'interfaccia grafica;

_ suggerire possibili miglioramenti relativi all'organizzazione e alla leggibilità del codice.

Ogni suggerimento e codice fornito dall'AI è stato fatto messo in discussione, facendolo spiegare ed analizzare dall'AI stessa. In caso di soluzioni non gradite, ne è stata richiesta una modifica, con conseguente spiegazione ed analisi della nuova alternativa proposta
