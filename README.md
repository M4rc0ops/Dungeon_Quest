# DUNGEON QUEST

Dungeon Quest è un GDR che si basa sulla scalata di una torre a tre piani con nemici da affrontare e boss da sconfiggere.

# COMANDI DI GIOCO
I Comandi per Giocare a Dungeon Quest sono:

WASD -> Movimento

Z -> Attacco

Esc -> pausa

# REQUISITI

I requisiti per compilare ed eseguire il gioco sono:

_Gradle -> versione 9.8.2
 
_Java -> versione 25 (LTS)
 
_Javafx -> versione 25

 # AI

Sono stati utilizzati strumenti AI come:

_Gemini -> per la realizzazione delle immagini

_ChatGPT -> per minima assistenza alla scrittura del codice, confronto e implementazioni di funzionalità
